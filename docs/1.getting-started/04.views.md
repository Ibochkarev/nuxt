## `app.vue`

![The app.vue file is the entry point of your application](/assets/docs/getting-started/views/app.svg)

By default, Nuxt treats this file as the **entrypoint** and renders its content for every route of the application.

```vue [app/app.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
  </div>
</template>
```

::tip
If you are familiar with Vue, you might wonder where `main.js` is (the file that normally creates a Vue app). Nuxt does this behind the scenes.
::

## Components

![Components are reusable pieces of UI](/assets/docs/getting-started/views/components.svg)

Most components are reusable pieces of the user interface, like buttons and menus. Create them in the [`app/components/`](/docs/directory-structure/app/components) directory, and they are automatically available across your application without explicit imports.

::code-group

```vue [app/app.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
    <AppAlert>
      This is an auto-imported component.
    </AppAlert>
  </div>
</template>
```

```vue [app/components/AppAlert.vue]
<template>
  <span>
    <slot />
  </span>
</template>
```

::

## Pages

![Pages are views tied to a specific route](/assets/docs/getting-started/views/pages.svg)

Pages are views for each specific route pattern. Every file in the [`app/pages/`](/docs/directory-structure/app/pages) directory represents a different route and displays its content.

To use pages, create an `app/pages/index.vue` file and add the `<NuxtPage />` component to [`app/app.vue`](/docs/directory-structure/app/app) (or remove `app/app.vue` for the default entry). Create more pages and routes by adding files to the [`app/pages/`](/docs/directory-structure/app/pages) directory.

::code-group

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
    <AppAlert>
      This is an auto-imported component
    </AppAlert>
  </div>
</template>
```

```vue [app/pages/about.vue]
<template>
  <section>
    <p>This page will be displayed at the /about route.</p>
  </section>
</template>
```

```vue [app/app.vue]
<template>
  <div>
    <NuxtPage />
  </div>
</template>
```

::

## Layouts

![Layouts are wrapper around pages](/assets/docs/getting-started/views/layouts.svg)

Layouts are wrappers around pages with a common user interface for several pages, such as a header and footer. A layout is a Vue file with a `<slot />` component to display the **page** content. Nuxt uses the `app/layouts/default.vue` file by default. Set a custom layout as part of your page metadata.

::note
If you only have a single layout in your application, we recommend using [`app/app.vue`](/docs/directory-structure/app/app) with [`<NuxtPage />`](/docs/api/components/nuxt-page) instead.
::

::code-group

```vue [app/app.vue]
<template>
  <div>
    <NuxtLayout>
      <NuxtPage />
    </NuxtLayout>
  </div>
</template>
```

```vue [app/layouts/default.vue]
<template>
  <div>
    <AppHeader />
    <slot />
    <AppFooter />
  </div>
</template>
```

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>Welcome to the homepage</h1>
    <AppAlert>
      This is an auto-imported component
    </AppAlert>
  </div>
</template>
```

```vue [app/pages/about.vue]
<template>
  <section>
    <p>This page will be displayed at the /about route.</p>
  </section>
</template>
```

::

See the [Layouts section](/docs/directory-structure/app/layouts) for more layouts and how to use them in your pages.

## Advanced: Extending the HTML Template

::note
If you only need to modify the `<head>`, you can refer to the [SEO and meta section](/docs/getting-started/seo-meta).
::

You can take full control of the HTML template by adding a Nitro plugin that registers a hook. The callback of the `render:html` hook lets you mutate the HTML before it is sent to the client.

```ts [server/plugins/extend-html.ts]
import { definePlugin } from 'nitro'

export default definePlugin((nitroApp) => {
  nitroApp.hooks.hook('render:html', (html, { event }) => {
    // This will be an object representation of the html template.
    console.log(html)
    html.head.push(`<meta name="description" content="My custom description" />`)
  })
  // You can also intercept the response here.
  nitroApp.hooks.hook('render:response', (response, { event }) => { console.log(response) })
})
```
